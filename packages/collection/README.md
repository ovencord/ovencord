## About

`@ovencord/collection` is a powerful utility data structure used in `@ovencord/discord.js` that uses no dependencies.

## 📦 Installation

**Bun 1.0.+ is required, but we recommend always using the most up-to-date version**

```sh
bun add @ovencord/builders
```
